## Narrative (the funnel)

The article (`docs/diagonality.md`) **claims** benefits of diagonality —
and hedges them as "(assumed)". → We extract those claims as hypotheses
H1–H4, quoted literally from Spielverlagerung. → We **build** the
orientation-aware framework (vision → OA-PPCF → DOS → scanning gate). →
We **validate**: does the 3D data confirm the article? → DOS is the
deliverable: a real-time, per-opponent map of where a diagonal delivery
breaks a blind defender.

The hero is **DOS as a real-time engine**, not the trade-off table; the
trade-off is supporting evidence inside "does the data confirm the
article?".

---

## Structure (main.tex)

1. **Introduction** — two coaching dogmas as one axis; the diagonal
   optimum; orientation unmeasurable until 3D skeleton; 4 contributions.
2. **Related Work** — pitch control → action value → D-Def → vision →
   biomechanics → off-ball runs (industry). The unfilled intersection.
3. **Data** — 5 Bundesliga matches, TRACAB 21-keypoint skeleton @ 50 Hz,
   6,923 on-ball actions + 2,354 off-ball runs. Table of the 5 matches.
4. **The Claims of Diagonality** — H1 perception / H2 bi-axial / H3
   receiver / H4 trade-off, each a literal Spielverlagerung quote.
5. **Methods** — 5.1 orientation + vision, 5.2 OA-PPCF, 5.3 DOS, 5.4
   scanning gate (the real-time engine), 5.5 event metrics + run
   detection + validation design.
6. **Results: does the data confirm the article?** — 6.1 trade-off [H4],
   6.2 DOS predicts xT, 6.3 mechanism I defender [H2], 6.4 mechanism II
   receiver [H3], 6.5 off-ball runs, 6.6 the coaching deliverable + case
   study.
7. **Applications** — match prep, post-match, recruitment, broadcast.
8. **Limitations & Future Work** — 5 matches; learned run detector;
   OA-PPCF AUC; DOS↔D-Def relationship.
9. **Conclusion.**

## Numbers cheat-sheet (consistent with the generated figures + reports)

- Trade-off: forward n=1,137 / diagonal n=2,272 / sideways n=3,514;
  positive-xT rate 71% / 79% / 30%; retention (completed pass, or ball
  kept through carry/take-on) 77% / 89% / 96%.
- DOS↔xT: MWU all p=1.16e-25; carries rbc +0.40, p=1.2e-36. Logistic dos
  coef +10.9, p=2.6e-5 (controls: distance, pressure, defender counts).
  Quintiles positive-xT rate 43→48→55→58→61%.
- D-Def: diagonal PC2 > forward PC2 p=7.0e-12; combined PC1+PC2 p=2e-4.
  DOS↔D-Def ρ=-0.30 (complementary, not redundant).
- Receiver (passes): head-to-goal rotation forward 145° / diagonal 108° /
  sideways 60° (diag<fwd p=1.6e-59); team-mates in FOV 5.0 / 6.0 / 5.1
  (diag>fwd p=6.7e-11).
- Off-ball runs: 2,354 detected; mean 2.8 s, 16.8 m, 6.4 m/s peak; 89.8%
  positive DOS; run-DOS forward 0.0095 / diagonal 0.0089 / sideways 0.0038.
